I've just done a bit of a blog tidy up in the process of adding a few talks from the last few years. All this is necessitated by the need to gather information for a review into NCAS. I find that if I tidy all the information into my blog, it's a good place to source the stuff needed by the bean-counters, now and in the future.  

If you want to see what has changed, most of it is currently on the front page where there are quite a lot of new talks listed, though not all the new ones are there (see the [summary list]({{ '/talks/summary/' | relative_url }}) for the full set). If you are reading this in the future, you might not care about what has changed, but while doing that I had a look at my latest CV and realised I had a word cloud in there that may be a bit old, so thought I'd generate a new one:

{% include image.html url="/assets/images/2026-11-18-word-cloud.png" caption="Word Cloud for Bryan Lawrence
Refereeed Publications" width="480" align="center" %}

To be fair, it's not that different to the old one (not surpringly), but there are some things I like about the
new one, particularly the progression down the middle from commmunity, to measurements, simulations, modelling,
climate, and data! I've done a lot of different things and have been glad to have quite a varied career (thus far, it aint over yet).

This particular word cloud was generated by taking the `publications.md` file that I generate for this blog
(by using pyzotero to download my publications and create the nicely formatted markdown) and selecting only the refereeed outputs. I used chatgpt(yeah, sorry) to strip to titles. It was fed to [cloudmywords.com](https://cloudmywords.com) where I chose 150 words, circular layout, and the vivid layout. (As an aside, this did not work in the brave browser, but did in Safari).
